# Posting Cadence

Cadence rules per objective, runtime, and platform.

## By objective

### Awareness

- One wave
- Staggered across 2 days
- 1 slot per platform

### Consideration

- One wave
- Staggered across 3 days
- 1 slot per platform

### Conversion

- Two waves: primary and reinforcement
- Primary wave staggered across 2-3 days
- Reinforcement wave 5-7 days later
- 1 slot per platform per wave

### Authority

- One wave
- Staggered across 2-3 days
- Optional re-post wave 14 days later

### Full campaign

- Wave structure per the campaign plan in brief
- Typically 3-4 waves across 30 days

## By runtime

### 15s

- Higher cadence allowed
- One wave plus optional re-post wave 7 days later

### 30s

- Standard cadence
- One wave plus optional re-post wave 14 days later

### 60s

- Standard cadence
- One wave, re-post only if performance warrants

### 90s

- Conservative cadence
- One wave

## By platform

### LinkedIn

- 1 post per wave
- Tuesday-Thursday preferred
- No more than 1 post per day

### Instagram Reels

- 1 post per wave
- Weekdays preferred, weekends allowed
- No more than 1 post per day

### TikTok

- 1 post per wave
- Daily posting allowed for high-cadence briefs
- No more than 2 posts per day

### YouTube Shorts

- 1 post per wave
- Weekdays preferred
- No more than 1 post per day

### X

- 1 post per wave; thread if the metadata requires
- No more than 3 posts per day

## Wave structure

- A wave is a group of slots sharing a start date and covering all platforms in the run.
- A wave's platforms are all the platforms in the distribution pack.
- A wave's slots are staggered per the cross-post strategy.
- A wave's end date is the day of the last slot in the wave.

## Re-post rules

- A re-post uses a different caption, hashtag set, and thumbnail.
- A re-post does not use the identical metadata.
- A re-post does not violate the platform's duplicate-content policy.
- A re-post is scheduled at least 7 days after the primary wave.

## Cadence changes

- Cadence can change between waves.
- Cadence cannot change mid-wave.
- Cadence changes are recorded in calendar.json.

## Rejected patterns

- Posting the same platform twice in one day without a re-post wave
- Posting every platform within a single hour (triggers duplicate-content filters)
- Posting LinkedIn on a weekend without a brief override
- Posting a re-post with the same caption as the original
- Posting 5 platforms on the same day and calling it a staggered cross-post
