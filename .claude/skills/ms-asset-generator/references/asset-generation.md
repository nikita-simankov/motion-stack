# Asset Generation

How to produce each asset type. Sources and rules.

## Authored

Assets designed by the studio. Used for logos, brand marks, illustration, UI components, data components.

Rules:

- Source files kept in runs/<project-id>/assets/src/
- Exports written to runs/<project-id>/assets/
- Deterministic file names (id-based)
- SVGs and raster exports must match the frozen palette

## Client-supplied

Assets provided by the client. Logos, brand imagery, product screenshots, fonts.

Rules:

- Client assets are placed in runs/<project-id>/assets/client/
- License record references the client agreement
- Any client asset that conflicts with the frozen palette is either adjusted to match (allowed for logos and marks only) or flagged
- Client logos must not be re-colored without written permission in the license record

## Licensed library

Assets sourced from a paid library: icons, illustrations, sound-adjacent imagery.

Rules:

- License record references the library and the seat
- Attribution appended to metadata when required
- Any asset with a restricted territory excludes the target audience and fails

## Public domain

Assets from public domain sources.

Rules:

- Source URL recorded
- License recorded as public domain
- Attribution optional but recommended

## Generated

Assets generated by code: data components, UI components, patterned textures.

Rules:

- Code kept in runs/<project-id>/assets/src/
- Deterministic output
- No randomness at render time unless seeded
- Match frozen palette and type

## Rejected sources

- Stock sites without an explicit license record
- AI-generated imagery without disclosure and clearance
- Community sites without a named author
- Any asset with an unclear origin
- Any asset that would require reverse image search to attribute

## Naming

Deterministic naming scheme:

A<id>_<purpose>_<slug>.<ext>

Example:
A001_hook_diagram-mcp.svg
A002_body_data-plate.webp
A003_ui_device-frame.tsx

No spaces. No camelCase in filenames. Lowercase and hyphens only.

## Directory layout

runs/<project-id>/assets/
A001_hook_diagram-mcp.svg
A002_body_data-plate.webp
A003_ui_device-frame.tsx
...
src/ # source files
client/ # client-supplied originals
licenses/ # license PDFs or reference files

## Verification

Before gate pass, verify:

- Every asset opens without error
- Every asset matches its declared dimensions or viewBox
- Every asset hash matches the manifest
- Every asset loads via its declared loader in a Remotion test composition
