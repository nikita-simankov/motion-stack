# Client Profiles

Load when --client flag is set.

--client <profile> loads:

- Voice rubric override
- Palette and style token override
- License rules and approved music sources
- Deliverable list and naming convention
- Approval chain and required sign-offs
- Remotion composition templates and defaultProps overrides
- ElevenLabs voice_id and model preferences
- UI mockup style guide: device frame, corner radius, shadow spec, interaction state set

Profiles stored at runs/\_clients/<profile>.json.
