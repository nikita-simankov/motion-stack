# Hook Adaptation

Platform hook patterns, accepted and rejected starts.

## Rules

- The hook is the first 2 seconds. On TikTok, the first 0.5 seconds.
- The hook is either the master hook (when the platform's culture allows) or a re-cut hook.
- A re-cut hook uses only footage already in the master.
- A re-cut hook uses the frozen style tokens.
- No new scenes.
- No new assets.

## Per platform

### LinkedIn

Accepted:

- Specific number as a hero ("4.2 billion calls a quarter.")
- Contradiction ("The faster path is the slower one.")
- Named subject with a professional frame ("MCP broke our pipeline.")

Rejected:

- Slang
- Emoji in the first frame
- Questions the audience would find rhetorical

### Instagram Reels

Accepted:

- Visual moment as the hero (an animation at its peak)
- Surprising claim
- Named subject with a bold visual

Rejected:

- Slow open
- Logo
- Title card
- Text that requires pausing to read

### TikTok

Accepted:

- Frame-one motion at the visual peak
- Frame-one text that reads as a claim
- Native-sounding provocation

Rejected:

- Slow open
- Establishing shots
- Any cut that assumes the viewer's attention
- Logo
- Title card

### YouTube Shorts

Accepted:

- Frame-one text that reads as a claim or a question
- Frame-one motion at the visual peak
- Slightly more explanatory than TikTok

Rejected:

- Slow open
- Logo
- Title card
- Anything that reads as an ad

### X

Accepted:

- Text-dominant hook
- On-screen text that reads at 25% scale
- A specific claim or a specific number

Rejected:

- Text that requires sound to understand
- Text too small to read at 25% scale
- Logo
- Title card

## Re-cut hook procedure

When the master hook does not fit the platform:

1. Identify the strongest visual moment in the master within the platform's acceptable range.
2. Re-order the scenes to lead with that moment.
3. Re-time the hook to fit the platform's first-2-second window (or the first 0.5 seconds on TikTok).
4. Preserve the original hook's claim, only change the packaging.
5. Re-render.

Rules:

- A re-cut hook preserves the claim.
- A re-cut hook does not change the script.
- A re-cut hook does not introduce a new claim.
- A re-cut hook uses a scene already in the master.

## Copy hook

Every platform's copy has a first line that functions as a second hook.

- LinkedIn — first line of the caption
- Instagram Reels — first line of the caption, and repeated as frame-one text
- TikTok — first line of the caption, matching frame-one text
- YouTube Shorts — title, and first line of the description
- X — first post text

Rules:

- The first line differs per platform.
- The first line is a claim, a number, or a provocation — never a summary.
- The first line is short enough to be visible before "see more".

## Testing

Ask three questions per platform hook:

1. Would this stop the scroll on this platform? (Yes / No)
2. Does it state the claim in the first 2 seconds? (Yes / No)
3. Could this hook work unchanged on a different platform? (Yes = bad)

Any "No" on 1 or 2, or "Yes" on 3, is a rewrite.

## Rejected

- Copy-pasting the master hook to every platform without adaptation
- Using a hook that requires sound on a muted-autoplay platform
- Using a hook that assumes context the platform audience lacks
- Using a hook that misrepresents the video
- Using a hook that violates the platform's community guidelines
