# Copy Adaptation

First line, caption body, CTA, hashtags per platform.

## First line

### LinkedIn

- First 210 characters visible before "see more"
- Lead with a specific claim, number, or professional observation
- No emoji in the first line
- No hashtag in the first line
- Example: "Most MCP deployments fail in the first week. Here's the pattern we keep seeing."

### Instagram Reels

- First 125 characters visible before "more"
- Lead with the video's frame-one text or a hook line
- Emoji allowed when the brand voice permits
- Example: "The MCP mistake almost every team makes 👇"

### TikTok

- First 100 characters visible before "more"
- Lead with the same line as the video's frame-one text
- Native, conversational
- Example: "Nobody talks about this MCP problem"

### YouTube Shorts

- Title: first 40 chars visible in search
- Description: first 150 chars visible before "show more"
- Lead with a question or a claim
- Example title: "The MCP deployment mistake"
- Example description: "Most teams deploy MCP wrong. Here's the fix."

### X

- The first post carries the whole hook
- Thread if the video needs more than 280 chars of context
- Example: "Most MCP deployments fail in the first week. A thread on why:"

## Caption body

### LinkedIn

- 3-6 sentences
- Specific, no fluff
- One CTA at the end
- Attribution and disclosure strings at the bottom
- Hashtags at the bottom

### Instagram Reels

- 2-4 sentences
- Emoji allowed
- CTA mid or end
- Attribution and disclosure strings at the bottom
- Hashtags in the first comment

### TikTok

- 1-3 sentences
- Native tone
- CTA end
- Attribution and disclosure strings at the bottom
- Hashtags at the end

### YouTube Shorts

- 3-6 sentences in the description
- CTA and subscribe prompt
- Attribution and disclosure strings at the bottom
- Hashtags in the description

### X

- Thread of 3-7 posts
- Each post under 280 chars
- CTA at the end
- Attribution and disclosure strings in the final post

## CTA

### LinkedIn

- Comment, follow, or link
- One CTA only

### Instagram Reels

- Save, share, or comment
- One CTA only

### TikTok

- Follow, comment, or soft "link in bio"
- One CTA only

### YouTube Shorts

- Subscribe or comment
- One CTA only

### X

- Repost, reply, or link
- One CTA only

## Hashtags

### LinkedIn

- 3-5 hashtags
- At the bottom of the caption
- Industry-relevant, not trending

### Instagram Reels

- 5-10 hashtags
- In the first comment
- Mix of niche and mid-reach

### TikTok

- 3-5 hashtags
- At the end of the caption
- Mix of niche and trending

### YouTube Shorts

- Up to 3 in the title area
- Up to 15 total in the description
- Relevant, not trending

### X

- 1-2 hashtags
- In the first post
- Relevant

## Rules

- No platform gets the same first line as another.
- No platform gets the same hashtag set as another.
- No platform gets the same CTA string as another.
- No duplicate hashtags within a platform's set.
- No banned hashtags (verify against the platform's list at the time of posting).
- No hashtag spam. Respect the platform's max.
- No clickbait the audience has learned to skip ("You won't believe").
- No misleading claims.
- No claims the dossier does not support.

## Attribution and disclosure

- Every attribution string from the license records is appended.
- Every disclosure string (AI voice, sponsored) is appended.
- Disclosures are placed prominently, not buried.
- No platform-specific suppression of a required disclosure.

## CTA library

The stage 4 script's CTA is adapted per platform. The action may differ; the intent is preserved.

Example: script CTA is "Read the full breakdown".

- LinkedIn: "Full breakdown in the comments."
- Instagram Reels: "Full breakdown in the caption 👆"
- TikTok: "Full breakdown in the first comment"
- YouTube Shorts: "Full breakdown below"
- X: "Full breakdown in the thread"

## Rejected

- Copy-paste of the same caption across platforms
- Same hashtag set on all platforms
- Same CTA string on all platforms
- Emoji abuse
- Excessive line breaks
- ALL CAPS hook lines unless the brand voice permits
- Any banned hashtag
- Any claim not supported by the dossier
