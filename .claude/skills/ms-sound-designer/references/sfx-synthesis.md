# SFX Synthesis

Generate custom SFX from a spec when no library match exists or when a signature sound is required.

## When to synthesize

- No library match for the placement
- A brand signature sound is required
- A frequency-specific element (e.g. a sub-drop in a musical key) is needed
- The brief's tone demands a non-library sound
- A client has requested a unique texture

## Synthesis spec

Every synthesized SFX carries a spec:

{
"type": "sub-drop | riser | tick | sweep | sweep-down | noise-burst | custom",
"params": {},
"generator": "string (script or tool)"
}

## Common types

### sub-drop

params:
frequencyStartHz: 200
frequencyEndHz: 30
durationMs: 600
curve: exponential
amplitude: 0.9
noiseLayer: false

Use for: impact landings, reveals, hard cuts.

### riser

params:
frequencyStartHz: 200
frequencyEndHz: 4000
durationMs: 1200
curve: exponential
noise: white | pink | brown
amplitude: 0.7

Use for: tension builds, transitions into drops.

### tick

params:
durationMs: 40
centerHz: 2000
q: 8
amplitude: 0.5

Use for: accents, type-on, small punctuations.

### sweep

params:
direction: up | down
frequencyStartHz: 500
frequencyEndHz: 8000
durationMs: 300
amplitude: 0.6

Use for: transitions, whooshes without noise.

### sweep-down

params:
frequencyStartHz: 8000
frequencyEndHz: 500
durationMs: 300
amplitude: 0.6

Use for: transitions out, closing movements.

### noise-burst

params:
color: white | pink | brown
durationMs: 80
envelope: sharp | soft
amplitude: 0.5

Use for: clicks, hits, glitches.

### custom

A generator script named in the spec. The script is invoked at render time with the params.

## Generator

- Synthesized SFX are generated by a script (Python or Node) stored under runs/\_sfx/synthesized/generators/.
- The script takes the spec params and outputs a WAV 48kHz 24-bit file.
- Determinism: the generator uses a fixed seed (recorded in the spec) so re-runs produce the same output.
- No unseeded randomness. No dependence on system time.

## Output

- File saved to runs/\_sfx/synthesized/<sfx-id>.wav
- Hash recorded in the SFX manifest
- Spec recorded in the placement's synthesisSpec

## Determinism

- Same spec + same seed → same output
- Re-running a synthesis is idempotent
- Any change to the spec produces a new hash; the previous file is archived under runs/\_sfx/synthesized/archive/

## Licensing

Synthesized SFX carry license source "synthesized". No external license is required. The generator script is licensed under the project's own terms.

## Quality checks

- No clipping (peak <= -1 dBFS)
- No DC offset
- No aliasing above Nyquist
- No unintended silences within the SFX body
- Envelope matches the spec's curve

## Rejected

- Synthesized SFX without a spec
- Synthesized SFX with unseeded randomness
- Synthesized SFX that requires a network call at generation time
- Synthesized SFX that cannot be regenerated from the spec
- Any synthesized SFX used without a quality check
